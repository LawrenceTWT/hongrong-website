## Source/build checks

- `npm run build`: shared layout synchronization, JavaScript syntax, six-page metadata/headings, local links/assets and English dictionary mappings
- Chinese font coverage is checked against the actual subset font hashes and codepoints
- Native links retain modified-click behavior; reduced-motion and no-JavaScript layouts retain normal reading flow
- No production dependency or framework migration was introduced

## Limits and follow-up

This is not a cross-browser or assistive-technology certification. Reduced-motion behavior was reviewed in source; it was not tested with a real device preference or screen reader.

The existing Wānaka image is 1536 × 1152. The registered landscape layers now keep the name readable, but a horizontal original at least 3000px wide is still needed for sharper large-desktop display. Replacing the photograph also requires retracing its ridgeline mask.
