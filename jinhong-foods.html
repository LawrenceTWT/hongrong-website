03技術 → 解決的問題

研究 / 架構 / 開發

技術用來解決
客戶會遇到的事

分類、產品頁與詢價清單，連成完整的瀏覽流程

  1. REACT + TYPESCRIPT可重用的產品頁面同一份資料結構連接分類、詳細頁、型號與規格
  2. RWD + CSS每種螢幕都能完成同一件事手機版仍能清楚導覽、閱讀產品並進入詢價
  3. LOCALSTORAGE先收藏產品，再進行聯絡詢價清單不需要帳號或資料庫也能使用
  4. VITE / CLOUDFLARE建置、部署與持續維護透過建置與 Cloudflare 部署，維護上線版本
